# fake-chat

一个用于自导自演虚构聊天记录的 iOS App。用户可以创建聊天角色、编写双方消息，并在微信、QQ、抖音私聊等风格的界面中预览，最终导出聊天图片。

项目目前处于初始化阶段，尚未创建 Xcode 工程，也没有可运行的 App。

## MVP 范围

- 管理本地聊天草稿。
- 设置聊天标题、参与者昵称和头像。
- 为双方添加、编辑、删除和调整文本消息顺序。
- 设置消息时间并显示时间分隔。
- 提供微信风格和抖音私聊风格的聊天预览。
- 将聊天记录保存到本地，并导出图片。

首版优先做完整的文本聊天流程。图片消息、语音外观、群聊和更多主题放在后续迭代。

## 技术方向

- 使用 Swift 和 SwiftUI 构建原生 iOS App。
- 优先使用 Apple 原生框架，首版离线运行，无需账号或后端。
- 聊天数据与主题界面分离，同一份记录可以切换不同主题。
- 创建工程时确定最低 iOS 版本、本地存储方案及具体构建命令，并更新本文件。

## 仓库约定

- 代码、标识符、文件名和注释使用英文；注释尽可能简洁，仅在必要时编写。
- 界面支持中文和英文。
- 文档和任务文件可以使用中文；每个开发任务在 `tasks/` 下使用独立的 Markdown 文件记录，按需创建。
- App 工程及源代码放在 `ios/`；有需要时再创建 `docs/`。
- AI 编程协作规则见 [AGENTS.md](AGENTS.md)。
- 不提交签名凭据、本地环境配置、构建产物及真实私人聊天内容。

## 产品定位

本项目用于虚构对话创作、剧情演示与界面预览，与微信、抖音及其运营方无关联。主题名称描述视觉参考方向；项目自身的名称、图标及素材应保持独立，使用原创或获得授权的资源。

## 开发起点

下一步创建最小可运行的 SwiftUI 工程，先实现“创建聊天 → 编辑双方文本消息 → 预览 → 本地保存 → 导出图片”的完整流程，再完善主题细节。
