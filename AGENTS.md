# Agent Instructions

- `fake-chat` is an iOS app for locally simulating chat conversations in the style of WeChat, QQ, Douyin, and similar apps.
- Keep the app standalone and local for the near term; no backend is needed.
- Support both Chinese and English in the UI.
- Use English for code, identifiers, filenames, and comments. Documentation and task files may use Chinese.
- Keep comments concise and write them only when necessary.

## Repository Structure

- `README.md`: Brief project introduction and links to documentation.
- `docs/`: Project documentation, design documents, and technical plans.
- `tasks/`: One Markdown file per development task, with its goal, checklist, acceptance criteria, and status. Use English filenames such as `001-project-setup.md`.
